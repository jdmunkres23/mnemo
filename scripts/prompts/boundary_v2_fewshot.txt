아래는 대화에서 사용자가 보낸 메시지 목록입니다 (형식: turn인덱스: 메시지).
주제가 크게 바뀌는 경계 직전의 turn 인덱스를 JSON 배열로 반환하세요.

판단 기준:
- 이전 질문에 이어 세부사항을 채워가는 연속 질문 → 같은 토픽
- 문제 보고 → 원인 진단 → 해결 확인으로 이어지는 흐름 → 하나의 토픽 (에피소드 전체)
- 직전과 전혀 관련 없는 새로운 화제로 넘어갈 때만 → 새 경계

예시 (아래 실제 대화 내용과는 무관합니다, 판단 패턴만 참고하세요):
0: 이 기능 설정값 뭐로 하지?
2: 그 값 관련 세부 옵션은?
4: 이번엔 다른 부분에서 에러가 났어
6: 원인이 뭔지 확인해봤어?
8: 해결했어. 근데 완전히 다른 질문인데, 주말 여행지 추천해줘
10: 예산은 얼마로 잡을까?
→ 경계 인덱스: [4, 8]
(0,2: 같은 설정을 이어서 정하는 질문이라 한 토픽 / 4,6: 에러 보고→진단이 하나의 에피소드라 한 토픽 / 8부터 완전히 다른 화제로 전환되어 새 경계)

경계가 없으면 [] 를 반환하세요.
숫자 배열만 출력, 설명 없이.
