# 논문 읽기 가이드

## 왜 읽기 전략이 필요한가

논문을 처음부터 끝까지 순서대로 읽으면 시간도 오래 걸리고, 읽고 나서도 뭘 읽었는지 흐릿해지는 경우가 많다. 목적을 먼저 정하고, 단계적으로 접근하면 같은 시간에 더 많이 남길 수 있다.

---

## 3단계 읽기 (Three-Pass Method)

### 1패스 — 전체 구조 파악 (5~10분)

아직 내용을 이해하려 하지 말고, 이 논문이 무엇에 관한 것인지만 파악한다.

- 제목, 초록(abstract) 읽기
- 섹션 제목들만 훑기
- 결론(conclusion) 읽기
- 그림, 표, 수식 제목만 눈으로 훑기

이 단계 후에 답할 수 있어야 하는 것:
- 무슨 문제를 다루는가?
- 어떤 방식으로 접근했는가?
- 결과가 어떻다고 주장하는가?
- 읽을 가치가 있는가?

### 2패스 — 흐름과 핵심 이해 (30~60분)

내용을 읽되, 모르는 세부사항에서 막히면 일단 넘어간다. 전체 흐름을 잃지 않는 것이 중요하다.

- Introduction: 왜 이 문제가 중요한가, 기존 연구의 한계는 무엇인가
- Method: 어떤 아이디어로 접근했는가 (수식보다 아이디어 먼저)
- Experiment: 어떤 설정으로 실험했는가, 비교 대상은 무엇인가
- Results: 핵심 수치, 어떤 조건에서 잘 되고 안 되는가
- Discussion/Limitation: 저자 스스로 인정하는 한계

중요한 문장, 이해 안 되는 부분, 의문이 드는 부분에 표시해두기.

### 3패스 — 깊이 있는 이해 (1~수 시간)

재현(reproduce)을 목표로 읽는다. 이 논문을 내가 직접 구현하거나 적용하려면 어떻게 해야 하는가.

- 수식과 알고리즘을 따라가며 이해
- 실험 설정의 세부 조건 확인
- 인용된 관련 논문 필요하면 확인
- 저자의 선택들이 왜 그렇게 됐는지 추론

## 섹션별 읽기 포인트

### Abstract
한 단락 안에 논문 전체가 압축되어 있다. 문제 → 방법 → 결과 → 의의 순서로 쓰인 경우가 많다. 첫 독해 후, 논문을 다 읽고 다시 읽어보면 이해도가 달라진다.

### Introduction
- 이 문제가 왜 중요한지 (motivation)
- 기존 방법들이 왜 부족한지 (gap)
- 이 논문이 무엇을 제안하는지 (contribution)
- 보통 마지막 단락에 contribution 목록이 있다

### Related Work
처음부터 자세히 읽지 않아도 된다. 나중에 "이 방법과 비슷한 연구가 뭐가 있지?" 궁금할 때 돌아오면 된다.

### Method
논문에서 가장 중요한 섹션. 그림과 알고리즘 박스를 먼저 보고 전체 구조를 파악한 다음 수식을 읽는 것이 수월하다.

핵심 질문: *이 방법의 핵심 아이디어가 뭔가? 기존 방법과 무엇이 다른가?*

### Experiments
- baseline(비교 대상)이 누구인가 — 공정한 비교인가?
- 데이터셋은 어떤 특성인가
- ablation study가 있다면 어떤 컴포넌트가 핵심인가
- 저자에게 유리한 설정만 보여주는 건 아닌가

### Conclusion
결과 요약 + 한계 + 향후 연구 방향. 저자가 어떤 부분을 아직 해결 못 했다고 보는지 확인할 수 있다.

## 비판적으로 읽기

논문이라고 해서 다 맞는 말이 아니다. 읽으면서 아래 질문들을 염두에 두면 좋다.

- 이 설정에서만 잘 되는 건 아닌가?
- 비교 baseline이 충분히 강한가, 최신인가?
- 하이퍼파라미터 튜닝이 특정 데이터셋에만 맞춰진 건 아닌가?
- 측정 지표가 실제 문제를 잘 반영하는가?
- 재현 가능성: 코드나 데이터가 공개되어 있는가?

---

## 논문을 읽는 목적에 따른 접근

| 목적 | 집중할 부분 |
|------|-------------|
| 분야 빠르게 파악 | Abstract + Introduction + Conclusion |
| 특정 방법론 이해 | Method 섹션 깊이 읽기 |
| 내 연구와 비교 | Experiments + Limitation |
| 구현/재현 | Method + 부록(Appendix) |
| 관련 문헌 조사 | Related Work + 참고문헌 목록 |

---

## 메모 습관

- 읽으면서 바로 적는다. 나중에 기억나겠지 하면 안 남는다.
- 요약보다 내 언어로 재해석한 것이 훨씬 오래 남는다.
- 이해 안 된 부분을 솔직하게 기록해두면 나중에 돌아봤을 때 진전을 확인할 수 있다.
- 논문 간 연결고리 (이 방법이 저 논문의 아이디어를 발전시킨 것 등)를 메모해두면 분야 구조가 잡힌다.
